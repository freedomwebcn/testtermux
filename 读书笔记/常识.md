# 一、政府的一般起源与设计：兼评英国政体

1.因此，既然安全是政府真正的设计原则和目的所在，我们就可以毫无怀疑地推断，不管什么样的政府形式，只要它看上去最有可能以最小的代价、最大的收益确保我们的安全，就是最可取的政府形式。

2.于是，需求就像一种凝聚力，很快将这些新近到来的移民聚拢成一个社会。在这个社会里，人们互惠互利，这种互惠关系胜过法律与政府的约束。**实际上，只要人们能始终真正做到公正相待，政府与法律的约束本是不必要的。** 但是，正如只有天堂里才没有邪恶，在这些人中间不可避免地会发生这样的事：他们克服了移居之初的种种困难——那些困难曾使他们为了共同的目标组织在一起，现在，他们开始懈怠了，忘记了彼此之间的责任与联系。这种懈怠说明了一个事实：有必要建立某种形式的政府，以弥补人们道德上的缺陷。

3.政府是由于人在治理世界上的道德缺陷而不得已采取的一种模式。

4.**绝对政府**是人性的耻辱，但也有其独特的好处，那就是它们都很简单。人们受苦受难，但知道苦难的根源，还知道医治苦难的良方，不会因五花八门的病因分析和治疗方案而无所适从。

5.君主政体的极端荒谬之处还不止于此。它一方面让一个人孤陋寡闻，另一方面又赋予这个人在需要英明决断的时刻行动的权力。国王的处境切断了他与外部世界的联系，但是国王的职位又要求他洞悉一切；两种不同的角色奇怪地截然对立，甚至互相败坏，这都证明，其整体就是一个荒唐、无用之辈。

6.只要处于某种压倒性的偏见的影响之下，我们就不能以一种正确的姿态公正地对待他人；同样，只要我们还在执迷不悟、自以为是，我们就不能正确地审视自己。一个沉湎娼妓的男子是不配选择或者评判妻子的；同样，对腐败的政府体制的偏爱，使得我们不能识别一个好的政体。

# 二、论君主与世袭

1.贫富分化是很好解释的，用不着提压迫、贪婪这类刺耳、难听的字眼。压迫通常是财富的结果，很少是——或者从来就不是——财富的手段。

2.虽然他们可以说：“我们选择你为我们的头领”，但他们不能在不经子孙正当认可的情况下，说：“你的子孙和子孙的子孙永远统治我们的子孙。”因为这样一种不明智、不公正、不自然的契约，有可能将子孙置于下一任无赖无知的国王的治理之下。圣贤之人在内心往往对世袭权利深怀鄙夷。有很多邪恶一旦确立就很难铲除，王权世袭制就是其中之一，因为很多人会因恐惧而顺从，还有些人会因迷信而退让，而那些有势力的人，会与国王一道盘剥其他的人。

3.对人类而言，世袭制岂止荒谬，简直是邪恶。如果它能确保继承王位的都是贤良之辈，倒也还有着神圣印记；但实际情况是，它向蠢人、恶人、庸人打开大门，那么它的本性就只剩下压迫了。那些人自视生来为王，他人都得服从，因此很快就变得不可一世。他们被选中脱离了其他人类，早就受到了自大思想的毒害；他们所处的世界与大千世界迥然不同，这使得他们几乎没有机会了解世人的真正意愿，他们一朝为政，就往往对大小国事一概无知、无措。

4.世袭制的另外一个坏处就是，王位可能属于一个孩子，无论其多么年幼；而摄政者打着国王的招牌，随时有机会、有野心背叛人们的信任。而当国王年迈昏弱，显露出人性的全部弱点时，这个民族同样会面临不幸。不管哪种情况下，公众总是牺牲品，总会有一个恶棍无赖利用国王的年幼或者年迈，为所欲为。

5.一个政体越接近共和制，国王的事务就越少。很难找到一个恰当的词去界定英国的政府。威廉·梅里迪斯爵士称其为“共和国”，但就其当前的状况而言，它配不上这个词。因为国王可以任意处置一切官职，腐化堕落，独揽大权，结果吞噬了平民院（政体中的共和部分）的作用，使英国几乎沦为与法国、西班牙一样的君主制国家。人们为名称而争吵不休，却不了解名称的含义。英国人引以为豪的，不是英国政体中的君主部分，而是其中的共和部分，即，从自己当中选出平民院的这样一种自由。因此我们很容易理解，一旦共和不再发挥作用，奴役必将到来。为何英国政体弊病缠身？那都是因为，君主毒害了共和，王室控制了平民院。

# 三、关于美利坚当前局势的思考

1.呜呼！我们受古代偏见的影响太久，我们因迷信牺牲得太多。我们自夸大不列颠的保护，但我们不想一想，她的目的在于利益，而不是情感。她保护我们，不是为了我们的利益去防范我们的敌人，而是为了她的利益去防范她的敌人。她要防范的那些对手，与我们没有任何其他利益矛盾，却正因为这个利益，总是我们的敌人。让大不列颠停止对大陆的愚弄吧，或者让大陆抛弃对大不列颠的依赖！那样，法国与西班牙一旦对不列颠开战，就会对我们和平。

2.因此，说不列颠是母国，这句话即便对，那也是对不列颠的谴责。何况有时候，这句话并不对，或者说只对了一部分。“父国”或“母国”这类词，被国王及其走狗们狡猾地借用，他们暗含宗教用心，企图利用我们轻信的弱点，从褊狭之见中获益。美利坚的母国是欧洲，而不是英国。这个新世界是来自欧洲各地的受迫害的、热爱公民自由和信仰自由的人们的避难所。他们逃离的，不是母亲的温柔怀抱，而是暴君的残忍压迫。就英国而言，迄今为止一个不争的事实就是，同样的暴政，当初驱使人们离乡背井，今天仍在加害他们的子孙。
